## The jobs are already out there

Technology communities publish useful openings in public GitHub issues and repositories. Those listings are direct, contextual, and easy to miss when candidates have to check each community separately.

**openings.dev** makes that public activity searchable without asking communities to publish the same role twice. Every result keeps its repository, author, and source link, so candidates can verify current details where the listing began.

```text
Public GitHub communities → Openings public data → openings.dev → original listing
```

## Explore the project

- [Search current jobs](https://openings.dev) by role, technology, location, work model, recency, and salary disclosure.
- [Browse community profiles](https://openings.dev/communities) and see which public sources have open roles.
- [Read the open data reports](https://openings.dev/reports) for monthly, versioned views of the index.
- [Understand the methodology](https://openings.dev/methodology), including source selection and known limitations.
- [Contribute to the official repository](https://github.com/openings-dev/web/blob/main/CONTRIBUTING.md) through code, documentation, source requests, and corrections.

## Public building blocks

- [`openings-dev/web`](https://github.com/openings-dev/web) — the official product, community, roadmap, and primary star destination.
- [`openings-dev/data-pipeline`](https://github.com/openings-dev/data-pipeline) — the versioned source catalog and generated public data.
- [`openings-dev/awesome-github-issues-job-boards`](https://github.com/openings-dev/awesome-github-issues-job-boards) — the generated directory of GitHub-based job boards.
- [Public npm packages](https://www.npmjs.com/org/openingshq) — reusable Openings foundations for the wider ecosystem.

Openings is open source, evidence-led, and built to help more people find the work communities already share.
